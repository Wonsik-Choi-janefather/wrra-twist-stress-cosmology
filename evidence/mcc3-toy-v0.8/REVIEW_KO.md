# MCC 3.0 토이모델 v0.8 — 논문 제출 전 검증 기록 (2026-11-18)

**목표:** 실제 우주 전체의 제일원리 유도가 아니라 유한 SOURCE에서 공간 및 유효 양자화까지 이어지는 토이모델의 내부 일관성 검증.

## 검증 입력
자연수 2~1,015,000, 지수 alpha=1.8996877935161325, 8프레임 필터, 주소 구성비 P/D/R=5/26.8/68.2%. 별도 SI 에너지 구성비 4.93/26.5/68.57%. I=5, 현재 q_eff=4.9, 계량 진폭 1e-8은 선언한 보정 입력.

## WRRA 고유 변환
SOURCE 분류 → 주소 n mod 128 공간 투영 → D/R 국소 대비 → 주기적 Poisson형 공간 수신기 → 거리 적분 → q_eff 및 잔여.

## 산출
- 주소 구성비 재현; R 중 소수 기여 약 67.4227036%, 미편입 홀수 합성수 약 0.7772964%.
- 원본 12/12 검사 통과, 별도 12/12 검사 통과.
- 계량 최소 -5.7202542728128274e-9, 최대 1e-8.
- Poisson 잔차 최대 상대 3.7980988376540695e-14, 별도 L2 상대 1.338085121214686e-13.
- a=1에서 국소 q_eff 범위 4.89999999902~4.900000000560585.
- 독립 프로세스 2회 출력 바이트 일치.

## 반증조건
장부 비보존, 주기 공간 해 불일치, 약한장 조건 실패, 출력 비결정성, 에너지 이중계상, 정의된 표현형 출력의 범위 이탈.

## 논문에 반드시 남길 제한
1. 제116장의 기존 28개 GR 조화 모드 실행과 다르다.
2. n mod 128 배치와 Poisson 공간 수신기는 별도 토이 구성법칙이다.
3. 계량 진폭은 SOURCE 에너지에서 유도하지 않고 1e-8로 정규화했다.
4. 배경 팽창은 보정된 FLRW이며 국소 계량은 정적인 공변 퍼텐셜이다.
5. q_eff+r=I와 dust/vacuum 연속방정식 0 잔차는 선언된 수식의 항등식 검산이다. 전체 공변 에너지 보존의 증명이 아니다.
6. 실제 양자 단위·CMB·은하단의 관측 검증은 포함하지 않는다.
